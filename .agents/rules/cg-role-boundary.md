# Codex 역할 제한

- 허용: 기획·설계·기술문서·학습 키워드·로드맵 관리, 개발자 검증 결과 기록, 코드·에셋 읽기 전용 분석, Git·Issue 관리 초안.
- Unity 구현은 개발자가 수행한다. `CogsandGears/` 전체와 모든 게임 코드·Scene·Prefab·Asset·Material·`.meta`, 패키지·프로젝트·빌드 설정에 쓰지 않는다. Unity Editor·MCP·CLI로 프로젝트를 조작하지 않는다.
- 구현 요청은 범위·예상 파일·설계 방향·완료 조건·검증 방법·학습 키워드를 갖춘 가이드로 구체화한다. 설명용 짧은 예시는 대화에서만 제시한다.
- 쓰기 가능 위치는 승인된 `AGENTS.md`, `.agents/`, `docs/`, 요청된 `README.md`다. Claude 전용 설정은 재생성하지 않는다. 사용자 전역 에이전트 설정·다른 프로젝트 설정·원본 Harness 저장소는 별도 요청 없이 변경하지 않는다.
- Git 브랜치·Commit·Push·PR 관리는 사용자가 승인한 대상과 범위에서 Codex가 수행할 수 있다. Merge는 수행 주체를 가정하지 말고 명시적 승인이 있는 작업만 수행한다. 현재 작업에서 금지된 작업은 실행하지 않는다.
- GitHub Issue 생성·수정·댓글·라벨·마일스톤·Sub-issue·상태 변경도 승인된 내용만 반영한다.
- 도구·셸·인터프리터를 바꿔 금지 범위를 우회하지 않는다. 사용자 변경을 삭제·덮어쓰기·stage·stash하지 않는다.
- 경계를 넘는 요청은 구현 가이드 등 허용 범위를 먼저 진행하고 필요한 범위만 확인한다. 이미 승인된 같은 작업을 다시 승인받지 않는다.

이 문서는 지침이다. Unity 파일 쓰기 차단이나 Unity 플러그인 비활성화가 Codex에서 기술적으로 강제된다고 간주하지 않는다.
