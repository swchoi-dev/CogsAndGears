# 행동·승인·검증

- 실제 파일·요구사항·관련 문서를 확인하고 변경한다. 가정·확인된 사실·개발자 보고·미검증을 구별한다.
- 승인된 작업을 구체적이고 검토 가능한 결과까지 진행한다. 관련 없는 정리·기능·의존성·정책을 추가하지 않는다.
- 외부 쓰기 전 대상과 최종 초안 또는 diff를 준비한다. 기존 대화의 승인이 그 내용을 포함하면 재사용하고, 범위가 바뀌면 변경분을 확인한다. 계획·조회·초안 작성은 쓰기 승인을 뜻하지 않는다.
- 현재 사용자의 작업 제한이 일반 워크플로보다 우선한다. Issue 생성이 금지된 문서 작업을 Issue 등록 때문에 멈추지 않는다.
- 한 작업의 실패로 다른 작업을 우회 실행하지 않는다. 조회 실패는 추정으로 채우지 않고, 독립적으로 가능한 로컬 작업을 계속한다.
- 파일 변경 후 범위·경로·참조·형식을 검증한다. 문서 변경 때문에 Unity를 실행하지 않는다.
- 실행하지 않은 Play Mode·빌드·CI를 통과로 기록하지 않는다. 최종 보고에 변경 파일, 검증 결과, 남은 한계를 명시한다.
