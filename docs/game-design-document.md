# Cogs & Gears — 원페이지 기획서

**버전:** v0.2 (초안)  
**장르:** 2.5D 횡스크롤 런앤건 로그라이크  
**플랫폼:** PC (우선 검토)  
**개발 엔진:** Unity 6

---

## 1. 한 줄 소개

**스팀펑크 세계에서 연금술사 Cogs와 고양이 동료 Gears가 적을 돌파하고, 획득한 장비를 연금술 가방에 배치·조합하며 자신만의 전투 빌드를 완성하는 2.5D 횡스크롤 런앤건 게임.**

- 플레이어는 연금술사 Cogs를 조작해 스테이지의 왼쪽에서 오른쪽으로 이동하며 적과 전투한다.
- 좌우 이동과 회피로 적의 공격을 피하고, 마우스로 자유롭게 방향을 조준한다. 장착한 공격 장비는 각자의 공격 주기에 따라 발동하므로, 플레이어는 이동·위치 선정·회피에 집중한다.
- 스테이지의 목표 지점에 도달하면 보상 3개 중 하나를 선택한다.
- **연금술 가방을 열어 내부 격자 공간에 획득한 장비와 시약, 유물을 배치하고 인접 시너지와 아이템 합성으로 장비를 강화**해 다음 스테이지를 준비한다.
- 고양이 Gears는 플레이어를 따라다니는 동료로 등장한다. (미구현)

## 3. 타겟 유저

- 횡스크롤 액션 게임에서 이동·회피·전투의 손맛을 즐기는 플레이어
- 로그라이크 게임의 반복 도전과 무작위 보상 선택을 좋아하는 플레이어
- 제한된 공간에서 아이템을 배치하고 시너지를 발견하는 빌드 구성형 게임을 선호하는 플레이어
- 3D 캐릭터 기반의 아기자기한 스팀펑크 분위기를 좋아하는 플레이어

## 4. 핵심 재미

**① 회피와 위치 선정 중심의 실시간 전투**

플레이어는 적의 공격을 회피하고 공격 가능한 위치를 유지하면서 전투한다. 공격 장비는 개별 주기에 맞춰 발동하므로, 단순 연타보다 이동과 생존 판단이 중요하다.

**② 연금술 가방을 활용한 전략적 아이템 배치**

제한된 가방 공간에 무기·유물·시약 등을 배치한다. 아이템의 크기, 위치, 인접 관계에 따라 효과가 달라지며, 동일 아이템을 합성해 장비를 강화할 수 있다.

**③ 전투 빌드의 성장과 시너지 발견**

스테이지마다 보상을 선택하면서 공격 방식과 장비 구성이 변화한다. 새로운 아이템 조합을 발견하고, 같은 장비라도 배치 방식에 따라 다른 전투 결과를 만드는 재미를 제공한다.

## 5. 화면 및 분위기

- **시점:** 2.5D 횡스크롤, 측면 고정 카메라
- **비주얼:** 3D 캐릭터와 환경을 활용한 스타일라이즈드 그래픽
- **세계관:** 톱니바퀴, 증기기관, 기계 장치, 연금술이 공존하는 판타지 스팀펑크
- **캐릭터:** 연금술사 Cogs와 장비를 착용한 고양이 Gears
- **전투 화면:** 캐릭터 이동과 적의 공격 패턴을 명확히 인지할 수 있는 구성
- **인벤토리 화면:** 가죽과 황동 장식의 연금술 가방을 펼친 형태. 내부에는 장비 수납용 격자와 연금술 반응을 나타내는 시각 효과를 배치
- **전체 분위기:** 귀엽고 모험적인 캐릭터 디자인과 기계 문명 특유의 신비로운 분위기

## 6. 반복 구조

**스테이지 전투 → 목표 지점 도달 → 보상 선택 → 연금술 가방 정비 → 다음 스테이지**

플레이어는 한 번의 Run 동안 여러 스테이지를 진행하며 장비와 시너지를 누적한다.

새로운 도전에서는 획득하는 보상과 구성하는 빌드가 달라지므로, 이전과 다른 무기 조합 및 가방 배치를 시도하게 된다.

반복 플레이의 동기는 더 강한 조합을 발견하고, 새로운 전투 스타일로 Run을 완주하는 데 있다.

## 7. 콘텐츠 구성

| 분류 | 주요 콘텐츠 |
|---|---|
| 플레이어 | 이동, 회피, 자유 조준, 장비 기반 공격 |
| 동료 | Gears의 플레이어 추종 및 동행 연출 |
| 적 | 근접형·원거리형 몬스터와 공격 패턴 |
| 스테이지 | 횡스크롤 진행형 전투 구간 및 목표 지점 |
| 장비 | 무기, 유물, 시약 및 일반 아이템 |
| 연금술 가방 | 격자 배치, 아이템 크기, 인접 시너지, 동일 아이템 합성 |
| 보상 | 스테이지 클리어 후 3개 중 1개 선택 |
| 진행 | Run 단위 반복 플레이, 스테이지별 빌드 성장 |
| 게임 흐름 | 타이틀 → Run → 스테이지 진행 → 클리어 또는 패배 → 결과 |

---

**기획의 핵심 방향:** 전투에서 살아남는 조작 능력과, 전투 사이에 연금술 가방을 구성하는 전략적 판단이 서로 영향을 주는 게임을 만든다.
