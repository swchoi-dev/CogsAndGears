# 미션 요구사항 추적표 — 구성안

- 기준일: 2026-11-10. PDF는 제공 경로의 9페이지 전체 텍스트와 이미지/흐름도/도해를 확인했다. 실제 파일 정보는 [조사 기록](implementation-audit.md)에 있다.
- 분류 1은 **미션의 필수 기능과 그에 수반되는 알고리즘·도해 확인 항목** 65행이다. 도해의 예시 수치·특정 모양·상태 이름을 유일한 정답으로 강제하지 않는다. 별도 “(필)”이 없는 메인 화면·옵션·에셋 조건도 제출 기준에서 빠뜨리지 않도록 포함했다.
- 대응 E/T ID는 [Issue 전체 초안](github-issues-plan.md)의 로컬 식별자다. 실제 GitHub 번호가 아니다.
- 상태: 완료=근거 있는 구현/설정 완료, 부분 구현=기초만 존재, 미구현=현재 사용자 콘텐츠에서 구현을 발견하지 못함, 확인 불가=자료/실행 근거 부족. 정적 확인은 Play Mode 성공을 의미하지 않는다.
- 표의 날짜는 **기능 목표 창**이며 가용시간 대비 부족분이 해소되지 않은 일정이다. [실현 가능성 평가](../roadmap.md)를 함께 읽는다.

## 5. 누락 검증과 남은 위험

- PDF p.1~9 모든 필수 기능 영역을 R01~R65와 T01~T39에 연결했다. **요구사항 반영 완료이며 구현 충족 완료는 아니다.**
- 배치·회전·인접·확장: T13~T18/T22/T36에 입력·처리 조건·예상 결과·수동 검증을 포함했다.
- 다중 무기·독립 주기·버프: T05/T18/T19/T21. 보상·정비·다음 층: T23~T28. SO/풀: T06/T10/T11/T12.
- UI는 HP/실드뿐 아니라 밖 적·피해 숫자·정지 가방 보기·결과 마지막 가방·볼륨·변경 이벤트까지 포함했다.
- 필수에 대응 Issue가 없는 행은 없다. 반면 시간 내 검증 완료를 입증하는 근거도 아직 없다. 11/20 일정 위험과 에셋 승인 불확실성을 미완료 후보로 유지한다.
- 선택인 합성·Gears·희귀도·추가 적을 뺀다고 필수 회전/인접/확장/적2종/필수UI를 뺄 수 있는 것은 아니다.
